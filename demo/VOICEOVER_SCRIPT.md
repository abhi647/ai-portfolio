# Demo voiceover script

Generated by `demo/record.mjs`. Each line starts at the timestamp shown in its video.

**Recommended ElevenLabs settings:** Multilingual v2 (or Turbo v2.5), a calm narrator voice, Stability ~50%, Similarity ~75%, Style 0–15%, Speaker boost on.

**Two ways to use it:**

1. *Per-scene clips (most accurate):* generate each line below as its own clip, name it after the scene ID (e.g. `A01.mp3`), put the clips in one folder and run `node voiceover.mjs --video admin --clips <folder>`. It places every clip at its timestamp and exports a voiced MP4.
2. *Single take:* paste `output/<video>/elevenlabs-single-take.txt` into ElevenLabs. It already contains `<break>` pauses sized to the scenes; nudge the audio in your editor if a line drifts.
